## DR-PRODUCT-TYPE-CREATE-001 {#dr-product-type-create-001}

- **Название**: Данные для создания вида изделий
- **Использует**: [F-PRODUCT-TYPE][]
- **Используется в**: [SF-PRODUCT-TYPE-CREATE][], [FR-PRODUCT-TYPE-CREATE-001][], [FR-PRODUCT-TYPE-CREATE-002][],
[AR-PRODUCT-TYPE-CREATE-001][]
- **Описание**: Состав полей записи справочника видов изделий (таблица `dict_product_type`) при создании: какие поля
передаёт пользователь, какие заполняет система, их типы и ограничения.

### Данные, которые передаёт пользователь {#dr-product-type-create-001-input}

Все перечисленные поля обязательны.

| Поле | Тип | Ограничения | Описание | Пример |
| :--- | :--- | :--- | :--- | :--- |
| `name_nominative` | VARCHAR(150) | Не пустое после обрезки пробелов по краям, не длиннее 150 символов | Наименование изделия | Кольцо, Браслеты, Серьги |
| `product_group` | ENUM | Одно из значений из таблицы ниже | Тип изделия | `JEWELRY` |
| `default_streak_count` | DECIMAL(5,2) | Больше 0 (допущение), не больше 999.99, не более 2 знаков после запятой | Количество натиров (базовое) | 1, 2, 3 |
| `wholesale_gold_streak_count` | DECIMAL(5,2) | Больше 0 (допущение), не больше 999.99, не более 2 знаков после запятой | Количество натиров для золотых изделий оптовой торговли | 0.5, 1 |
| `stamp_impressions_count` | INT | Целое число больше 0 (допущение) | Количество наложенных оттисков | 1, 3 |

### Значения `product_group` {#dr-product-type-create-001-groups}

| Код | Название |
| :--- | :--- |
| `JEWELRY` | Ювелирные изделия |
| `WEIGHT_PRODUCTS` | Весовые изделия |
| `WATCH_CASES` | Часовые корпуса |

### Данные, которые заполняет система {#dr-product-type-create-001-system}

| Поле | Тип | Значение при создании |
| :--- | :--- | :--- |
| `pk` | UUID | Уникальный идентификатор, который формирует система |
| `is_active` | BOOLEAN | `true`: созданная запись всегда активна |
| `created_at` | TIMESTAMP | Дата и время создания записи (UTC) |
| `updated_at` | TIMESTAMP | Равно `created_at` (допущение) |

### Ограничения {#dr-product-type-create-001-constraints}

- Первичный ключ: `pk`.
- Уникальность: пара из наименования `name_nominative` (без учёта регистра и пробелов по краям) и типа `product_group`
не повторяется (см. `H02`).
- Пустые значения (`NULL`) не допускаются ни в одном поле.

### Допущения {#dr-product-type-create-001-assumptions}

- **DR-PRODUCT-TYPE-CREATE-001.H01**
    - **Статус**: принято
    - **Подтверждает**: владелец справочника
    - **Допущение**: Количество натиров (базовое и для золотых изделий оптовой торговли) и количество оттисков больше 0,
      верхняя граница натиров 999.99 следует из типа DECIMAL(5,2).
- **DR-PRODUCT-TYPE-CREATE-001.H02**
    - **Статус**: принято
    - **Подтверждает**: владелец справочника
    - **Допущение**: Наименование уникально в пределах типа изделия: например, «Кольцо» может быть в группе `JEWELRY` и
      в другой группе, но не дважды в одной.
