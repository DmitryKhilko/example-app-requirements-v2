# Справочник стран {#country}

Страница будет формироваться автоматически.

На странице будет отображено: 
- Статистика по входящим в основную функциональность требованиям: количество в разрезе типов и статусов требований. 
- Перечень требований с гиперссылками для перехода к ним.
- Вопросы, требующие решений в рамках основной функциональности.
