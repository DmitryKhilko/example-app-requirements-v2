## Назначение {#purpose}

Справочник стран - единый источник данных о странах для адресов, контрагентов и документов других подсистем. Пакет описывает основную функциональность F-COUNTRY по слоям: от бизнес-целей до контракта API, модели БД и критериев приёмки. Из этих требований создаются код и автотесты, поэтому каждое утверждение проверяемо.
