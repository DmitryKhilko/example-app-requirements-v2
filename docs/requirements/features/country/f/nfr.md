### NFR-COUNTRY-001. Права доступа к справочнику стран {#nfr-country-001}

- **Описание**: Операции со справочником стран доступны только ролям, указанным в матрице. Просмотр активных стран
  доступен всем аутентифицированным ролям, кроме администратора ИБ. Просмотр неактивных стран и все изменяющие операции
  доступны только администратору ИС. Попытка выполнить операцию без права отклоняется, данные не изменяются, запись в
  журнал аудита не создаётся.
- **Матрица ролей**:

| Роль (Код) | Просмотр активных (`SF-COUNTRY-LIST`, `SF-COUNTRY-READ`) | Просмотр неактивных (`SF-COUNTRY-LIST`, `SF-COUNTRY-READ`) | Создание (`SF-COUNTRY-CREATE`) | Редактирование (`SF-COUNTRY-UPDATE`) | Активация / Деактивация (`SF-COUNTRY-ACTIVATION`) | Удаление (`SF-COUNTRY-DELETE`) | Импорт НСИ АСФР (`SF-COUNTRY-IMPORT`) | Код отказа при попытке |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :--- |
| **Администратор ИБ (`aib`)** | Нет | Нет | Нет | Нет | Нет | Нет | Нет | `FORBIDDEN` |
| **Администратор ИС (`ais`)** | Да | Да | Да | Да | Да | Да | Да | — |
| **Администратор СХ (`ash`)** | Да | Нет | Нет | Нет | Нет | Нет | Нет | `FORBIDDEN` |
| **Администратор подразделения (`ap`)** | Да | Нет | Нет | Нет | Нет | Нет | Нет | `FORBIDDEN` |
| **Пользователь подразделения (`pp`)** | Да | Нет | Нет | Нет | Нет | Нет | Нет | `FORBIDDEN` |
| **Администратор КО (`ako`)** | Да | Нет | Нет | Нет | Нет | Нет | Нет | `FORBIDDEN` |
| **Пользователь КО (`pko`)** | Да | Нет | Нет | Нет | Нет | Нет | Нет | `FORBIDDEN` |
| **Без входа (неаутентифицирован)** | Нет | Нет | Нет | Нет | Нет | Нет | Нет | `UNAUTHORIZED` |
