## Сценарии использования {#use-cases}

### UC-COUNTRY-001. Просмотр списка и поиск {#uc-country-001}

Пользователь просматривает список стран, ищет страну и меняет
сортировку.

- **Актор**: ais, ap
- **Относится к**: [BR-COUNTRY-001](#br-country-001), [BR-COUNTRY-002](#br-country-002), [BR-COUNTRY-009](#br-country-009)
- **Использует**: [SF-COUNTRY-LIST](sf-list/index.md), [MSG:country.list_empty](sf-list/index.md#msg-country-list-empty)
- **Предусловие**: Пользователь аутентифицирован.
- **Основной поток**:
    1. Пользователь открывает справочник стран.
    2. Система показывает первую страницу списка: 20 записей, сортировка по русскому названию по возрастанию.
    3. Пользователь вводит строку поиска, и система показывает подходящие страны.
    4. Пользователь переходит между страницами и меняет сортировку.
    5. Редактор или администратор включает показ неактивных стран, и они появляются в списке.
- **Альтернативы**:
    - **Ничего не найдено**: Система показывает сообщение MSG:country.list_empty.
    - **Читатель запрашивает неактивные страны**: Система отказывает с кодом `FORBIDDEN`, а в интерфейсе
переключатель читателю не показывается.
- **Постусловие**: Данные не изменились.

### UC-COUNTRY-002. Просмотр карточки страны {#uc-country-002}

Пользователь открывает карточку страны и видит все её поля.

- **Актор**: reference_reader, reference_editor, reference_admin
- **Относится к**: [BR-COUNTRY-001](#br-country-001), [BR-COUNTRY-009](#br-country-009)
- **Использует**: [SF-COUNTRY-READ](sf-read/index.md), [MSG:country.not_found](sf-read/index.md#msg-country-not-found)
- **Основной поток**:
    1. Пользователь выбирает страну в списке.
    2. Система показывает все поля страны.
- **Альтернативы**:
    - **Страна не найдена или неактивна для читателя**: Система показывает сообщение MSG:country.not_found.
- **Постусловие**: Данные не изменились.

### UC-COUNTRY-003. Создание страны {#uc-country-003}

Пользователь добавляет в справочник новую страну.

- **Актор**: reference_editor, reference_admin
- **Относится к**: [BR-COUNTRY-002](#br-country-002), [BR-COUNTRY-005](#br-country-005)
- **Использует**: [SF-COUNTRY-CREATE](sf-create/index.md), [SF-COUNTRY-READ](sf-read/index.md), [MSG:country.duplicate](#msg-country-duplicate)
- **Основной поток**:
    1. Пользователь выбирает "Добавить страну".
    2. Пользователь заполняет поля формы и сохраняет.
    3. Система проверяет данные, создаёт активную страну и показывает её карточку.
- **Альтернативы**:
    - **Ошибки заполнения**: Система подсвечивает поля и показывает причины.
    - **Страна уже есть**: Система сообщает, какое значение повторяется (MSG:country.duplicate).
- **Постусловие**: Создана одна активная страна, и записан аудит.

### UC-COUNTRY-004. Редактирование страны {#uc-country-004}

Пользователь меняет русское или английское название страны.

- **Актор**: reference_editor, reference_admin
- **Относится к**: [BR-COUNTRY-003](#br-country-003)
- **Использует**: [SF-COUNTRY-READ](sf-read/index.md), [SF-COUNTRY-UPDATE](sf-update/index.md), [MSG:country.not_found](sf-read/index.md#msg-country-not-found), [SF-G-LOCK](../../global/sf-g-lock/index.md)
- **Основной поток**:
    1. Пользователь открывает карточку и выбирает "Изменить".
    2. Пользователь меняет название и сохраняет.
    3. Система обновляет запись и показывает карточку.
- **Альтернативы**:
    - **Запись изменили раньше**: Система сообщает о конфликте по SF-G-LOCK и предлагает обновить карточку.
    - **Страну удалили**: Система показывает сообщение MSG:country.not_found.
- **Постусловие**: Названия изменены, версия записи выросла на 1, коды не изменились.

### UC-COUNTRY-005. Деактивация и активация страны {#uc-country-005}

Пользователь выключает или включает страну в выборе.

- **Актор**: reference_editor, reference_admin
- **Относится к**: [BR-COUNTRY-004](#br-country-004), [BR-COUNTRY-012](#br-country-012), [BR-COUNTRY-013](#br-country-013)
- **Использует**: [SF-COUNTRY-ACTIVATION](sf-activation/index.md), [SF-G-LOCK](../../global/sf-g-lock/index.md)
- **Основной поток**:
    1. Пользователь выбирает "Деактивировать" или "Активировать".
    2. Система меняет признак активности страны.
- **Альтернативы**:
    - **Запись изменили раньше**: Система сообщает о конфликте по SF-G-LOCK.
- **Постусловие**: Деактивированная страна не отображается читателям, активированная отображается.

### UC-COUNTRY-006. Удаление страны {#uc-country-006}

Администратор удаляет страну, на которую нет ссылок.

- **Актор**: reference_admin
- **Относится к**: [BR-COUNTRY-004](#br-country-004), [BR-COUNTRY-014](#br-country-014)
- **Использует**: [SF-COUNTRY-READ](sf-read/index.md), [SF-COUNTRY-DELETE](sf-delete/index.md), [MSG:country.in_use](sf-delete/index.md#msg-country-in-use)
- **Предусловие**: Пользователь аутентифицирован.
- **Основной поток**:
    1. Администратор выбирает "Удалить" в карточке страны.
    2. Система запрашивает подтверждение.
    3. Администратор подтверждает, и система удаляет страну.
- **Альтернативы**:
    - **На страну есть ссылки**: Система отказывает и предлагает деактивировать страну (MSG:country.in_use).
    - **Страну уже удалили**: Система закрывает диалог и открывает список.
- **Постусловие**: Страна удалена, записан аудит.

### UC-COUNTRY-007. Доступ без входа или без прав {#uc-country-007}

Пользователь без входа или без нужной роли пытается выполнить
операцию.

- **Актор**: пользователь без входа, reference_reader, reference_editor
- **Относится к**: [BR-COUNTRY-003](#br-country-003), [BR-COUNTRY-010](#br-country-010)
- **Использует**: [FR-COUNTRY-001](#fr-country-001)
- **Основной поток**:
    1. Пользователь пытается выполнить операцию, которая ему недоступна.
    2. Система отказывает: без входа с кодом `UNAUTHORIZED`, без нужной роли с кодом `FORBIDDEN`.
- **Постусловие**: Данные не изменились, аудит не записан.

### UC-COUNTRY-008. Актуализация справочника из НСИ АСФР {#uc-country-008}

Администратор получает актуальный перечень стран из ЕРК,
просматривает различия со справочником и применяет их.

- **Актор**: reference_admin
- **Относится к**: [BR-COUNTRY-015](#br-country-015), [BR-COUNTRY-016](#br-country-016), [BR-COUNTRY-017](#br-country-017), [BR-COUNTRY-018](#br-country-018), [BR-COUNTRY-019](#br-country-019)
- **Использует**: [SF-COUNTRY-LIST](sf-list/index.md), [SF-COUNTRY-IMPORT](sf-import/index.md), [MSG:country.import_applied](sf-import/index.md#msg-country-import-applied), [MSG:country.import_unchanged](sf-import/index.md#msg-country-import-unchanged)
- **Используется в**: [FR-COUNTRY-IMPORT-001](sf-import/index.md#fr-country-import-001)
- **Предусловие**: Администратор аутентифицирован, ЕРК доступна, другого импорта в работе нет.
- **Основной поток**:
    1. Администратор открывает "Импорт из НСИ АСФР" на экране списка стран.
    2. Администратор запускает получение данных, и система создаёт задание и сообщает, что получает данные.
    3. Система получает последнюю версию набора стран из НСИ АСФР, проверяет его и сравнивает со справочником.
    4. Система показывает отчёт: сколько стран будет создано, изменено и деактивировано и какие страны отклонены.
    5. Администратор просматривает отчёт, при необходимости фильтрует его по действию.
    6. Администратор подтверждает применение, и система применяет все различия одной операцией.
    7. Система показывает итог применения и MSG:country.import_applied.
- **Альтернативы**:
    - **Изменений нет**: Версия ЕРК совпадает с применённой или различий нет. Система сообщает MSG:country.import_unchanged, применять нечего.
    - **Импорт уже идёт**: Система отказывает с кодом `IMPORT_ALREADY_RUNNING` и показывает текущее задание.
    - **ЕРК недоступна или вернула некорректные данные**: Задание завершается сбоем с кодом из набора кодов сбоя, система показывает причину и предлагает повторить. Справочник не меняется.
    - **Справочник изменился после отчёта**: Применение отклоняется с кодом `IMPORT_PREVIEW_STALE`, администратор получает данные заново.
    - **Отчёт устарел**: Через 24 часа отчёт недоступен для применения (`IMPORT_STATE_INVALID`).
- **Постусловие**: Справочник изменён только после подтверждения, для каждого изменения записан аудит с источником import.
