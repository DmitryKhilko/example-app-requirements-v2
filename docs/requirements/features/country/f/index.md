# F-COUNTRY. Справочник стран {#f-country}
- **Приоритет**: must
- **Роли**: ais, ash, ap, pp, ako, pko
- **Относится**: [BG-001][BG-001]
- **Использует**: [SF-COUNTRY-CREATE][SF-COUNTRY-CREATE] 
- **Описание**: Справочник стран является единым, достоверным и управляемым источником данных для адресов, контрагентов 
и документов всех подсистем, что исключает расхождение и дублирование информации. Для поддержания его актуальности 
пользователь может управлять записями вручную (просматривать, искать, создавать, редактировать, изменять статус и 
удалять), а также обновлять данные через импорт из НСИ АСФР.

## Границы {#f-country-scope}

- **Входит**: Просмотр, поиск, создание, изменение, деактивация и удаление стран, импорт стран из НСИ АСФР, права
  доступа и аудит изменений.
- **Не входит**: Справочник регионов и городов, история переименования стран, запуск импорта по расписанию, загрузка из
  файла и из внешних классификаторов кроме НСИ АСФР, названия на языках кроме русского и английского, просмотр журнала
  аудита в интерфейсе и API.

## Допущения и открытые вопросы {#f-country-questions-hypotheses}

- **F-COUNTRY.Q01**
    - **Источник**: требования службы безопасности
    - **Статус**: открыт
    - **Решает**: владелец справочника
    - **Вопрос**: Какие названия имеют больший приоритет при расхождении: из НСИ АСФР или принятые в организации?
- **F-COUNTRY.H01**
    - **Источник**: требования службы безопасности
    - **Статус**: принято
    - **Подтверждает**: владелец справочника
    - **Допущение**: Функциональность не предоставляет просмотр аудита, запись аудита проверяется чтением хранилища.
- **F-COUNTRY.H02**
    - **Источник**: требования службы безопасности
    - **Статус**: принято
    - **Подтверждает**: владелец справочника
    - **Допущение**: Названия из НСИ АСФР перезаписывают ручные правки без отдельного подтверждения по каждой стране.
- **F-COUNTRY.H03**
    - **Источник**: требования владельца справочников
    - **Статус**: принято
    - **Подтверждает**: служба безопасности
    - **Допущение**: Срок хранения заданий импорта 12 месяцев (принят аналитиком).
