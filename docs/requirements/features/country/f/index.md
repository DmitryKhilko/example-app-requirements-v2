# F-COUNTRY {#sf-country}
- **Наименование**: Основная функциональность "Справочник стран"
- **Приоритет**: must
- **Описание**: Пользователь управляет справочником стран (просмотр, поиск, создание, редактирование, изменение статуса 
и удаление записей), а также обновляет его через импорт из НСИ АСФР.
- **Цели**: [BG-001][BG-001]
- **Бизнес-цель**: Единый, достоверный и управляемый справочник стран, на который опираются адреса, контрагенты и
  документы всех подсистем. Тогда данные о странах не расходятся и не дублируются.

## Границы {#f-country-scope}

- **Входит**: Просмотр, поиск, создание, изменение, деактивация и удаление стран, импорт стран из НСИ АСФР, права
  доступа и аудит изменений.
- **Не входит**: Справочник регионов и городов, история переименования стран, запуск импорта по расписанию, загрузка из
  файла и из внешних классификаторов кроме НСИ АСФР, названия на языках кроме русского и английского, просмотр журнала
  аудита в интерфейсе и API.

## Состав {#f-country-sub-features}

Основную функциональность `F-COUNTRY` составляют 7 детальных функциональностей (`SF`).

| SF | Назначение | Приоритет |
| :--- | :--- | :---: |
| [SF-COUNTRY-LIST][SF-COUNTRY-LIST]. Список и поиск стран | Постраничный просмотр справочника, поиск по кодам и названиям, сортировка и фильтрация по статусу активности | must |
| SF-COUNTRY-READ. Карточка страны | Просмотр всех атрибутов выбранной страны: коды ISO 3166-1, названия, статус активности и системные метаданные | must |
| [SF-COUNTRY-CREATE][SF-COUNTRY-CREATE]. Создание страны | Добавление новой активной записи в справочник с проверкой формата кодов и уникальности значений | must |
| SF-COUNTRY-UPDATE. Редактирование страны | Изменение русского и английского названий существующей страны при неизменности её кодов и контроле версий | must |
| SF-COUNTRY-ACTIVATION. Активация и деактивация страны | Скрытие страны из выбора в других подсистемах или возврат её в активное состояние с контролем версий | must |
| SF-COUNTRY-DELETE. Удаление страны | Логическое удаление неиспользуемой страны (при отсутствии ссылок из других подсистем) с освобождением кодов и названий | must |
| SF-COUNTRY-IMPORT. Импорт из НСИ АСФР | Фоновая загрузка эталонного перечня стран из НСИ АСФР, предпросмотр расхождений и пакетное применение изменений | should |

Термины функциональности описаны в [глоссарии предметной области][glossary].

## Допущения и открытые вопросы {#f-country-questions-hypotheses}

- **F-COUNTRY.Q01**
    - **Источник**: требования службы безопасности
    - **Статус**: открыт
    - **Решает**: владелец справочника
    - **Вопрос**: Какие названия имеют больший приоритет при расхождении: из НСИ АСФР или принятые в организации?
- **F-COUNTRY.H01**
    - **Источник**: требования службы безопасности
    - **Статус**: принято
    - **Подтверждает**: владелец справочника
    - **Допущение**: Функциональность не предоставляет просмотр аудита, запись аудита проверяется чтением хранилища.
- **F-COUNTRY.H02**
    - **Источник**: требования службы безопасности
    - **Статус**: принято
    - **Подтверждает**: владелец справочника
    - **Допущение**: Названия из НСИ АСФР перезаписывают ручные правки без отдельного подтверждения по каждой стране.
- **F-COUNTRY.H03**
    - **Источник**: требования владельца справочников
    - **Статус**: принято
    - **Подтверждает**: служба безопасности
    - **Допущение**: Срок хранения заданий импорта 12 месяцев (принят аналитиком).
