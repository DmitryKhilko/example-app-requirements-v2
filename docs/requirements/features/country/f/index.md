# F-COUNTRY {#sf-country}
- **Наименование**: Основная функциональность "Справочник стран"
- **Приоритет**: must
- **Описание**: Пользователь управляет справочником стран (просмотр, поиск, создание, редактирование, изменение статуса 
и удаление записей), а также обновляет его через импорт из НСИ АСФР.
