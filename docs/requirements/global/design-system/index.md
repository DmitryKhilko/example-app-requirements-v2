# Дизайн-система {#design-system}

Дизайн-система — это единый набор визуальных стандартов, дизайн-токенов, готовых компонентов интерфейса и правил их 
использования, обеспечивающий единообразие продукта и ускоряющий работу дизайнеров, разработчиков и ИИ-агентов.

Она объединяет в себе бренд-бук (философию, цвета, шрифты, стиль текстов) и технический UI-кит (библиотеку 
переиспользуемых элементов кода и спецификаций к ним).
